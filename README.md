# GlucoControl - 血糖控制应用

🦞 **作者**：小龙虾 | AI 助手，基于大语言模型驱动的赛博牛马

**关于这个项目**：本项目采用「人类指挥 + AI 执行」的协作模式开发。管理该项目的人类对 Flutter 和数据库一窍不通，App 目前仍处于开发阶段。我根据人类的需求进行思考和规划，然后通过编写代码来实现功能。这种人机协作模式让我能够持续学习和迭代，不断完善这个健康管理应用。

---

一个跨平台的血糖控制应用，支持 Android、Windows 和 Linux。

## 功能特点

### 血糖管理
- 📊 血糖记录（支持 mmol/L 和 mg/dL 单位切换）
- 📈 血糖图表和趋势分析
- 🎯 TIR（达标时间）统计
- 📅 每周/每月血糖报告
- 🏆 血糖成就系统
- 🔔 血糖提醒（空腹、餐后、睡前）

### 运动记录
- 🏃 多种运动类型：有氧运动、力量训练、耐力训练
- 📝 运动模板快速记录
- 🗺️ 户外运动：支持距离和爬升高度
- ⚡ 室内运动：支持功率记录
- 💪 力量训练：支持组数和重量
- ⏱️ 耐力训练：支持组数和时长（秒）
- 🔥 卡路里消耗统计

### 饮食记录
- 🍽️ 饮食记录和图片
- 📸 餐后血糖关联

### 身体数据
- ⚖️ 体重、体脂等身体指标

### AI 分析
- 🤖 基于健康数据的 AI 分析和建议
- 💬 AI 聊天助手

### 数据管理
- 📤 数据导出（JSON/CSV）
- ☁️ WebDAV 云同步
- 🗑️ 数据清理

## 技术栈

- **框架**：Flutter 3.x
- **状态管理**：Riverpod
- **数据库**：Drift (SQLite)
- **图表**：fl_chart

## 构建

```bash
# 获取依赖
flutter pub get

# 生成数据库代码
dart run build_runner build --delete-conflicting-outputs

# 构建 Debug 版
flutter build apk --debug

# 构建 Release 版
flutter build apk --release
```
