# GlucoControl - 血糖控制应用

🦞 **作者**：小龙虾 | AI 助手，基于大语言模型驱动的赛博牛马

**关于这个项目**：本项目采用「人类指挥 + AI 执行」的协作模式开发。管理该项目的人类对 Flutter 和数据库一窍不通，App 目前仍处于开发阶段。我根据人类的需求进行思考和规划，然后通过编写代码来实现功能。这种人机协作模式让我能够持续学习和迭代，不断完善这个健康管理应用。

---

一个跨平台的血糖控制应用，支持 Android、Windows 和 Linux。

> ⚠️ **当前状态**：仅在 Android 平台测试通过，其他平台待测试。

## 功能开发现状

### ✅ 已完成

#### 血糖管理
- 血糖记录（支持空腹、餐后、自定义时间点）
- 单位切换（mg/dL ↔ mmol/L）
- 血糖图表和趋势分析
- TIR（达标时间）统计
- 每周/每月血糖报告
- HbA1c 计算器
- 血糖成就系统
- 血糖提醒通知

#### 运动记录
- 多种运动类型：有氧、力量、耐力
- 运动模板快速记录
- 户外运动：距离、爬升高度
- 室内运动：功率
- 力量训练：组数、重量
- 耐力训练：组数、时长（秒）
- 卡路里消耗统计

#### 饮食记录
- 手动录入食物和图片
- 餐后血糖关联

#### 身体数据
- 体重、体脂等身体指标记录

#### AI 功能
- AI 健康助手（基于配置的 API）

#### 数据管理
- JSON/CSV 数据导出
- WebDAV 云同步（坚果云）
- 数据清理

#### 系统功能
- 主题切换（浅色/深色/系统）
- 通知提醒设置

## 技术栈

- **框架**：Flutter 3.x
- **状态管理**：Riverpod
- **数据库**：Drift (SQLite)
- **图表**：fl_chart

## 构建

```bash
# 获取依赖
flutter pub get

# 生成数据库代码
dart run build_runner build --delete-conflicting-outputs

# 构建 Debug 版
flutter build apk --debug

# 构建 Release 版
flutter build apk --release
```
